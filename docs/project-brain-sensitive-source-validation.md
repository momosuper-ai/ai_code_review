## 已验证的行为

- 凭证与路径、名称同值时，保留私有规范来源及不透明身份，对模型输入和公开知识统一脱敏；原SHA、blob、行范围、关系状态不变。
- 所有计划源码摘录先扫描，完成source_privacy屏障后才进入语义编译。已付检查点先认证，再生成临时安全副本。
- 显示路径与属性键碰撞不覆盖条目；敏感路径关闭直接链接。Markdown、JSON、图、元数据、API及ZIP使用同一公开Schema2。
- 迟到的有效隐私发现先登记，再检查旧租约是否还能推进。已封存时隔离版本；未结算/未知调用或预留阻止ready，费用仍保留。
- 项目身份登记覆盖不同构建和分支；丢失已登记身份目录不会自动换key。Windows等价路径写法统一比较，跨盘符、共享或越界仍拒绝。
