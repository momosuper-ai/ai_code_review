## 请求与费用

`transport.py` 为隐私与语义调用提供同一个发送接口。每次 SDK 发送之前，单独持久化 UUID、调用组、组内序号与完整预算预留；SDK 和 LLMClient 的重试次数仍为 0。

只有 OpenAI SDK 的 `APIStatusError`，携带受支持的真实 `httpx.Response` 或 `httpx2.Response`，且状态为 429、500、502、503、504，才可能进入局部恢复。还必须同时满足：已关闭、流已消费、完整 `.content` 缓存可以无 I/O 访问、两个状态字段均为整数且一致。两个状态标志本身不保证读取完整：仅读取首块再关闭，也可能同时为 true。分类器不调用 read/aread 来补读，不凭状态属性或错误文本信任任意对象。错误正文不解析、不记录，也不能充当隐私发现。

`src/core/http_transport.py` 明确列出两个后端的响应类和超时类；旧 SDK 没有安装 httpx2 时继续使用 httpx，其他导入错误不静默忽略。超时诊断仍只检查有界异常链中的类型；HTTP 状态错误本身的 `transport_phase=unknown` 不代表已确认某个连接阶段。适配器实现及两个 HTTP 包的版本均纳入配方。

| 情况 | 处理 |
|---|---|
| 符合上述条件的完整临时 HTTP 错误 | 原调用记为 `http_error`，保留完整费用上界，有限退避后新 UUID 再发 |
| 401/403、402、其他非白名单状态 | 不自动重试；交由原失败处理保留费用和诊断 |
| 超时、断连、取消、部分响应或进程丢失 | 不推断请求未发送；仍为 reserved/unknown，阻止封存 |
| JSON、证据或隐私响应不合规 | 不借 HTTP 恢复绕过原校验；继续执行原有严格协议 |
| 没有持久调用计量器的诊断 | 不自动增加模型请求 |

`PROJECT_BRAIN_MODEL_HTTP_RETRIES=2` 表示每个逻辑请求最多追加两次。退避以 2、5 秒起步并增加至多 1 秒抖动；只接受数字 Retry-After 秒数，最大等待 30 秒。单元累计 6 个已关闭 HTTP 错误为数据库持久上限，跨投递、租约和 API 重试保留。次数、退避实现与配置均纳入生成配方。

关闭操作只从单元活动预留扣除原上界，构建总占用不减少，不创建实际 TokenUsage，不称为零费用。再次请求需要额外预留；预算不够就停止。有歧义的 unknown 不允许事后依据错误时间、用户描述或重试成功改为 http_error。

## 保持知识与隐私质量

扫描输出或格式重试的必要 reasoning 时，原语义响应始终保留在当前内存。仅重试本地扫描请求，不重新生成语义输出，不保存未扫描正文，不重新投递以丢弃该响应。

所有实际扫描尝试均计入原输入 8 次/输出 64 次扫描限制、480 秒工作窗口和构建预算。退避计入工作时间；预留前、预算等待后、实际发送前均检查。耗尽次数或窗口时终止单元，不能由普通 Celery retry 重置上限。

每次尝试重新读取隐私历史和 HMAC，重建安全输入；预算等待结束后还会重建。若实际输入超过已预留边界则不发送。响应的发现、候选位置和完成收据绑定此次真正发送的安全输入与成功 UUID。错误调用没有发现或完成收据资格。

正式产物仍要求所有必要单元完成、完整证据与最终隐私校验通过。调用门禁逐组验证相同构建、单元、租约、角色、阶段、用途、模型与格式轮次，序号连续，前序均为合法 http_error，最后必须为该组真正 settled 的成功调用；同单元其他成功不能替代。reserved、unknown、不认识的状态或未恢复组仍阻止发布。隐私来源中引用的调用额外要求真正 settled，不能使用 http_error。

## 用量和清单

构建占用等式为：已结算实际/估算 Token + 全部已关闭 HTTP 错误的完整预留。unknown 或在途预留另外阻止 ready。

用量 API 增加 `closed_http_error_calls`、`closed_http_error_reserved_tokens`、`ambiguous_reserved_tokens`；兼容字段 `unknown_reserved_tokens` 包含前两种费用不确定性，按角色、模型与阶段分别展示。存在已关闭错误时仍不给精确全构建占比，金额没有价格依据仍为 null。

正式 manifest 在完整扫描后、投影和封存前记录调用数、费用未知上界、已结算用量、占用和 `model_usage_financially_exact`。ready 事务再次对账；不在封存后补改清单。有效来源引用与重试成功不能代表业务解释准确率，冻结 50 题仍需对照固定源码独立评估。
