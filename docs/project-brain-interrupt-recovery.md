# Project Brain 中断与认证异常

2.2.1 修复恢复读取期间的软超时误分类，并保证当前隐私索引读取的一致性。固定 SHA、来源认证、费用和隐私门禁保持有效。

## 中断保留控制语义

Celery 的 `SoftTimeLimitExceeded` 属于 `Exception`。恢复适配器的通用异常包装曾把它转换为 `RecoveryPrivacyError`，随后变成终态来源认证错误，导致原本可以按任务规则处理的超时首轮就终止构建。

恢复层现在透传这个实际异常类型，并检查有界的异常原因/上下文链，以识别下层校验器已包装的同一中断。不根据错误文本或供应商正文分类，不把凭据、来源或模型内容写入日志。普通损坏、未知异常、MAC 不匹配、父材料变化和非法来源仍闭合失败。

这只恢复正常任务分类。若本次请求存在在途或未知费用，原有账目和 `model_calls_incomplete` 门禁仍会阻止重新发送；没有收到的模型响应不能被补造为成功。

## 当前索引的并发读取

同一构建的兄弟任务可能提交合法隐私发现。旧读取先刷新账本、再单独读取索引，两个操作之间的合法提交可能被误判为认证损坏。

当前 key、seal、索引和来源认证改为在既有索引锁下取得一致快照，采用与写入者相同的锁顺序。父材料、历史和数据库验证在这个短锁外执行；查找前后当前版本发生变化时，继续走原有“不复用该次收据”的路径。父不可变快照的变化仍直接拒绝。

## 运行边界

WSL 常驻进程只能保持发行版活动，不能阻止 Windows 整机进入待机。待机可能使工作进程、数据库读取和观察进程受到暂停或调度限制，但任务的软/硬期限仍可能到达；墙钟耗时不能直接当作模型耗时。

本机长任务测试应保持电脑唤醒。中断后先核对 Windows 电源事件、容器生命周期、任务租约和每次调用账目，再确定恢复方式。不能仅凭休眠时间重叠认定所有错误都由休眠造成。

本修复改变完整审计配方，不能把新实现直接注入旧付费构建。保留旧费用、未知额和成功检查点；后续执行须使用认证恢复流程，并符合已有授权范围。
