# Project Brain 2.3.2 汇总收敛与异常分类修复

后续真实验证在模型概览输出预算处停止，2.3.3已进一步实现字段预算及量化有界纠正，见[概览字段预算说明](project-brain-summary-field-budget.md)。本文保留2.3.2的原设计及验证范围；实际部署与正式验收以AGENT.md为准。

2.3.1完整验证在上层概览停止：固定输入的只读重放确认，第二层两个子概览合并后的实际传输保守上界34,747超过原包限制32,000，无法归并。`CompilationLimitError`继承`ValueError`，又被汇总包装层捕获，变为普通契约错误，导致无意义的三次任务尝试；该失败单元没有模型调用。

2.3.2为**模型新写的概览文字**增加独立生产者约束。title、所有texts、所有unknowns和document_path按完整JSON的UTF-8字节合计，不能超过原包预算的八分之一（最小128、最大8192）；默认32,000包得到4,000字节概览。机器赋予的来源范围不算模型文字，但仍经过原认证。约束直接写入系统提示，不进入公开知识的coverage或原始事实。

完整但过长的响应进入现有有界格式纠正；只回传固定反馈和已检查的必要reasoning，不回传过长正文。次数用尽后返回明确容量终态。隐私处理后及检查点封装前再次验预算。概览是有损综合，全部叶结论、引用、关系与历史未知项保留在规范详情，不截断字符串或删除坏条目凑结果。原32,000包、24子节点、8层、480秒工作窗口和费用保护不扩大。三个汇总包装层透传容量异常，来源损坏仍按来源契约拒绝。

离线候选已通过161项定向、Linux断网2099项全量单测（0跳过）。在原固定bundle和127叶结果上使用合成有界producer，4轮94节点完成全部层级；最大wire31,919，叶结果与历史未知项保留。这证明有界producer下的规划和安全边界，实际模型是否满足契约及知识质量仍须真实完整构建和冻结50题验收。

新输出约束改变共享编译代码和完整recipe，历史结果能否复用必须由实际组件认证决定，不能将新代码注入旧付费单元。旧构建、费用、unknown与所有submitted journal保留；部署、真实构建与质量结果以根目录AGENT.md为准。
